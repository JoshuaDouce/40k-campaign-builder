Campaign focus

From War Round 1 the tab bar shrinks to five tabs. Reading material moves behind Reference, with a quieter row of page buttons under the bar. Setup (round 0) is unchanged.

Notes for frontend: proposed class nav.subtabs
nav.subtabs{display:flex;gap:2px;overflow-x:auto;scrollbar-width:none;margin-inline:-4px;padding-inline:4px;
  background:var(--panel);border-bottom:1px solid var(--line)}
nav.subtabs::-webkit-scrollbar{display:none}
nav.subtabs button{flex:0 0 auto;min-height:40px;font-family:var(--f-body);font-size:15px;font-weight:500;
  letter-spacing:.01em;background:none;color:var(--dim);border:0;border-bottom:3px solid transparent;
  border-radius:0;padding:6px 10px 3px;cursor:pointer}
nav.subtabs button[aria-selected="true"]{color:var(--brass);border-bottom-color:var(--brass);
  font-weight:700;background:var(--panel2)}
  • Markup: <nav class="subtabs" aria-label="Reference pages"> with <button aria-selected>, rendered directly after the main nav.tabs (aria-label "Campaign sections"), only while Reference is the main tab.
  • Uses only existing tokens. No new colours or fonts. Focus ring comes from the existing global button:focus-visible.
  • Not sticky: only the main bar sticks. The sub-row scrolls away with the page, which keeps the pinned header short on a phone.
  • Sentence-case body font at 15px (not mono caps) is what makes it read as secondary and lets all five labels fit at 400px without scrolling. If a longer label or a 360px screen overflows, the row scrolls sideways like nav.tabs.
  • At 600px and wider, the main bar wraps; the sub-row needs no wide rule since it always fits.
