4 · Add unit: Datasheet pick-list

All states show the Add unit sheet for a Necrons player unless stated. The sheet's other fields are shown only for context. "MFM 1.6" sits small beside the Datasheet label whenever data is in use.

4aEmpty field, focused

Placeholder names the faction. No list until the player types. Plain typing still works with the list closed.

4bTyping "imm": matching rows

List drops under the field and overlays the fields below. Rows are 44px or taller, points on the right ("from 80" if several sizes, else "100 pts"). Legends sit below current units, with a Legends tag. The list caps at about 5 rows and scrolls, so the field stays visible above the keyboard. No "use as typed" row: the field text is simply what is saved.

On-screen keyboard area
4b-iiTyping "anr": Legends-only match

Legends rows are marked even when nothing else matches. Matching ignores case, apostrophes and curly quotes.

4cPicked a multi-size datasheet

Model-count choice appears under the field, default is the smallest size. Base points is filled and still editable. Tap the choices to see Base points and Effective points change.

4dPicked a single-size datasheet

One price, so no model-count row. The sheet layout does not shift beyond the missing row.

4eLoading datasheets

Brief and non-blocking: the field is live, the player can type and save. No MFM label until data arrives, then the list appears if the field has text.

4e-iiFallback: no data, or load failed

Exactly today's plain text field. No list, no MFM label, no error message, saving is never blocked.

4fBlack Templars: chapter and generic units mixed

Player is Black Templars, typed "cha". Chapter units (Chaplain Grimaldus, Emperor's Champion) and generic Space Marines units (Chaplain, Chaplain on Bike) sit together in one A-Z list with no visual distinction. A name in both sets shows once. No Blood Angels units appear.
