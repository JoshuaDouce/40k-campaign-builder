# Battles no longer grow supply; kills move XP in the unit form

Added 2026-10-25.

## Supply
Battles no longer add 150 pts to anyone's supply limit (both players, or the attacker in a garrison battle, used
to gain it). A supply limit is now 750, plus supply from Outposts and Ruins held, plus Muster and Reinforcements
(1 RP for +200). No battles had been recorded in the live campaign, so no saved supply needed converting.

## Kills and XP
In the Edit unit form, changing Kills by any whole number moves XP by the same amount (never below 0). XP can
still be typed directly, which is how Marked for Glory's +2 is added by hand. The post-battle helper already gave
+1 XP per kill and is unchanged. Seasoned Recruits stay fixed at 3 XP.
