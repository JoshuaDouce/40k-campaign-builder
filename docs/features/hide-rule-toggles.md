# Campaign rule switches are owner-only

Added 2026-10-26.

- The **Campaign rules** panel at the top of the Rules tab (the four switches with On/Off badges) only shows for the
  campaign owner. Players no longer see it.
- Players still know what's on: Setup step 4 lists the active rules ("Campaign rules: …"), and the Rules tab text
  follows them (slots or Datasheet limit wording, Knights and Toughness stages paragraphs).
- The "Campaign rules" button in Setup step 4, which jumps to the switches, shows for the owner only.
- Use the owner's "View as" picker to check the player view.
